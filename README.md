# Eventia Location

Prérequis : Node.js 20+ et MongoDB local.

## Branches

- `main` — version stable
- `develop` — intégration
- `feature/client-service`
- `feature/equipment-service`
- `feature/reservation-service`
- `feature/notification-service`
- `docs/analyse-conception`

## Démarrage

1. Dans chaque `services/*` : `npm install`, copier `.env.example` vers `.env`, `npm start`
2. Dans `frontend` : `npm install`, `npm run dev`

Le frontend ne doit pas être modifié.
